# 账号文章库与阅读工作台

点击页面顶部 **阅读工作台**，展开或收起右侧区域。在工作台内部通过“文章库”标签或 ＋ 浏览账号文章。文章库、现有 AI 助手和已打开的文章共用一个显示区域，每次只显示当前标签的内容。

## 账号存储

文章通过现有登录身份保存到服务器 SQLite 数据库，属于当前账号。同一账号在其他设备登录后，可以通过文章库读取。文章与语音会话独立，删除会话不会删除文章。未登录时文章库显示登录入口。

数据库启动时自动新增 articles 表与索引，保留现有账号、语音历史和其他表。无需手动迁移。删除清除正文并保留 UUID 删除标记，防止晚到的创建或保存请求重新创建文章。备份时请继续备份原有完整数据库。

## 阅读与编辑

点击文章打开标签；再次打开同一篇文章会激活已有标签。有正文的文章默认进入“阅读”视图，自动呈现 Markdown 的标题、引用、分隔线、代码块、列表、表格、强调和链接。点击“实时预览”，在同一区域边写边看：点击段落编辑该段 Markdown 源码，其他段落继续显示排版效果；离开段落后重新呈现排版。方向键在段落开头或末尾切换到相邻段落，“＋ 新段落”在文末继续写作。列表、引用、表格和代码块作为完整 Markdown 块编辑。需要直接修改全文时可切换“编辑源码”。切回“阅读”时立即尝试保存，并定位到当前编辑的段落。新建空文章默认进入实时预览。标题可以直接编辑，标签名称跟随标题。

正文没有 TTS 输入框的字数限制，首版最多保存 **500,000 Unicode 字符**，标题最多 200 字。空正文和空标题允许保存；空标题标签显示“未命名文章”。列表显示标题、字符数、添加时间，搜索覆盖标题和正文。阅读呈现不会改写服务器保存的源码，也不会让文章全文进入 AI 或 TTS。

实时预览支持 Ctrl+Z 撤销和 Ctrl+Y / Ctrl+Shift+Z 重做，切换段落后仍保留本次编辑历史；刷新页面或用全文源码/服务器版本替换正文后重新开始记录。缩放工作台时活动段落自动重算高度，输入或粘贴多行时跟随光标滚动。

关闭标签只关闭视图；删除需要确认，并从账号文章库移除文章、标签、待保存任务和本地草稿。重命名入口会选中文章标题，改动按相同自动保存流程提交。

标签切换保留编辑、滚动及 AI 状态；阅读、实时预览、源码编辑保留各自滚动位置和当前视图，实时预览还恢复光标，刷新后继续编辑。阅读与实时预览切换按源码段落对应位置，源码编辑切到阅读时对应到编辑区当前可见段落。输入法候选词未确认时暂不切换视图，以免打断组合输入。标签超过可见宽度后横向滚动，也可用方向键、Home、End 切换标签。右侧拖拽、键盘调整、双击重置宽度以及展开/收起沿用现有机制；窄屏仍使用一个右侧抽屉，在抽屉内部切换标签。

## 自动保存与草稿保护

停止输入约 1 秒后自动保存。切换、关闭标签、隐藏页面时尝试立即保存；关闭整个页面时浏览器可能中断网络，因此不依赖最后一次请求，未确认内容提前写入本地草稿。页面存在未保存内容时提供浏览器离开提示。

- **等待保存**：存在尚未提交的改动。
- **保存中**：请求已发出；期间继续编辑的内容仍等待后续确认。
- **已保存**：当前标题与正文都已收到服务端确认。
- **保存失败**：保留编辑和草稿；点击“重试保存”，恢复网络后也会重试。
- **版本冲突**：另一设备或浏览器标签已更新；停止自动写回，显示本地草稿与可查看的服务器版本。选择“使用服务器版本”，或确认“保留本地并保存”。再次出现并发更新仍会重新提示。

每篇文章拥有独立、串行的保存任务。服务端 revision 校验防止旧修改覆盖新版本。创建 UUID 是幂等标识，网络失败后重试不会重复创建。

本地草稿按账号 ID、文章 ID 和浏览器标签所有者分开存储，同一账号的不同浏览器标签不会互相清理草稿。刷新时与服务器版本比较后恢复。离线刷新仍能显示已有草稿，写回前先验证服务器版本。若在新浏览器标签恢复其他标签的草稿，需要明确选择；有多个外来草稿时首版展示最新一份，其他份仍留在其原浏览器标签中。退出登录或切换账号会取消旧请求、计时器并清空旧账号界面；保留的草稿只会在原账号登录后恢复。不要清除浏览器站点数据，除非已确认需要的改动都保存成功。浏览器配额不足时明确显示草稿保护失败，服务器保存仍可继续。

日文输入法组合输入时只保护本地中间内容，候选词确认后才提交。冲突选择等待期间如果继续编辑，保留新输入并要求重新选择；保留本地前发现服务器又有更新时，也会先刷新对照内容，避免覆盖未看到的版本。关闭已保存标签后重新打开，会重新读取服务器版本。

当前打开标签、选中标签、阅读位置以及工作台宽度只保存在当前浏览器，不随账号跨设备同步。恢复会重新打开仍未保存的草稿，便于处理之前关闭标签后的保存失败。

## 文件导入

在文章库点击“导入文件”，支持一次选择多份 **.txt / .md**。每个文件创建独立文章，以不含扩展名的文件名为标题，导入后打开对应标签并自动保存。

两种格式均保存原始文本源码，阅读视图自动呈现常见 Markdown；普通文本也可以直接阅读。UTF-8 严格解码，支持 UTF-8 BOM；读取失败或无效编码会显示具体文件名和错误。单文件最多 2 MiB，同时遵循正文 500,000 字和标题 200 字限制。导入保留正文及原始换行；实时预览只修改正在编辑的源码范围，沿用该段落的换行格式，其他内容保持原样。全文源码编辑使用浏览器 textarea 的标准 LF 换行。失败的新建保留本地草稿和重试入口。

Markdown 阅读使用项目内的轻量渲染模块，不是完整 CommonMark 实现。暂不支持数学公式、Mermaid、代码语法高亮或内嵌 HTML；HTML 源码按文字显示，图片显示说明文字，阅读时不加载外部图片。链接仅允许 HTTP、HTTPS、mailto 和页内锚点。

暂不支持 PDF、Word、网页、OCR、富文本、全文 AI 分析或自动内容合并。

## 选文用于语音

在阅读视图或源码编辑区选中文字，点击“选中文字 → 语音输入”。阅读视图填入选中的可见文字，源码编辑区填入选中的原文；均保留选区换行。没有正文选区时按钮禁用，不会默认发送全文。输入框已有未发送内容时询问是否覆盖。填入后继续遵循既有 TTS 字数限制，由用户点击发送生成语音。

AI 助手只解释中间当前会话最后一次提交的完整文本。选文、文章编辑、切换文章标签，以及中间尚未提交的草稿均不会改变 AI 对象；切回 AI 标签保留其提问、回答和请求状态。

## API 与验证

所有 /api/articles 路由要求现有账号认证。Cookie 写请求沿用 CSRF 和来源校验；文章 owner 始终取自服务端身份，不接受客户端 user_id。

| 接口 | 功能 |
| --- | --- |
| GET /api/articles?q= | 搜索与列表，不返回正文 |
| POST /api/articles | 幂等创建，传入 UUID id、title、content |
| GET /api/articles/{id} | 详情 |
| PUT /api/articles/{id} | 更新 title、content，必须传入当前 revision |
| DELETE /api/articles/{id} | 删除 |

文章请求体独立限制为 4 MiB，不改变 TTS 请求体限制。前端发送 X-Article-Account 预期账号，服务端核对实际身份，避免换账号时在途创建写入新账号。版本不一致返回 409；已删除文章重试创建返回 410。
